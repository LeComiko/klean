# Étape 34, lot A2 — Le premier lancement : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un patron qui vient d'installer KLEAN par le script ouvre son domaine, saisit le code d'installation affiché par le script, crée son entreprise et son compte administrateur dans le navigateur — sans aucun mot de passe écrit dans `.env`, et sans que le code survive à l'installation.

**Architecture:** Deux routes anonymes `GET/POST /api/installation` (`InstallationController`), gardées par le code d'installation (`CodeInstallation` : 20 symboles d'un alphabet fixe, empreinte SHA-256 comparée en temps constant). La création de l'entreprise et de l'administrateur est extraite d'`AmorcageService` dans `ServiceInstallation` — transaction, verrou consultatif, relecture des comptes —, appelée **sous la RLS** par la route (`ITenantContext.PoserEntrepriseInstallation()` tire l'identifiant et en fait l'entreprise de la requête) et **au propriétaire** par l'amorçage. Au démarrage sans compte : trois variables d'amorçage → création ; sinon code → l'API attend l'assistant ; sinon refus de démarrer. Côté écran, un assistant en quatre écrans. Côté script, plus aucune question d'administrateur ; le code est affiché en dernier, une fois le certificat obtenu, et retiré de `.env` dès qu'un compte existe.

**Tech Stack:** ASP.NET Core 10, EF Core 10 + Npgsql, Identity, xUnit (`backend.Tests`, collection `api`, base `klean_test`), React 19 + TypeScript + react-router-dom, `node --test` (`frontend/scripts/tests.mjs`), bash (`deploiement/`, série dans Debian 12).

**Source du cadrage :** `SPEC.md`, étape 34, « **Lot A2 — Le premier lancement** » (6 points) et la ligne **A2** du paragraphe « Tests ». Lire `CLAUDE.md` §6 (amorçage, comptes), §7 (RLS, `BasculeRoleApplicatif`), §10 (pièges), §11, §14.

```csharp
using System.Security.Cryptography;
using System.Text;

namespace Klean.Api.Services;

/// <summary>
/// Le code d'installation (SPEC.md, étape 34, lot A2) : la seule garde de
/// <c>POST /api/installation</c> entre le démarrage et la première visite. Les journaux de
/// transparence des certificats publient un domaine en quelques minutes : sans code, quiconque
/// le lirait pourrait s'emparer de l'entreprise.
///
/// Vingt symboles de <see cref="Alphabet"/> — celui de <c>generer_code</c> dans
/// <c>deploiement/fonctions.sh</c>, sans I, L, O, 0 ni 1 —, environ 100 bits. La saisie est
/// normalisée (casse, espaces, tirets) puis comparée par empreinte, en temps constant.
///
/// ⚠️ <b>Un code configuré hors de cette forme fait refuser le démarrage</b> : configuré à
/// moitié, comme un SMTP incomplet (CLAUDE.md §2) — et un code recopié d'un exemple serait
/// connu de tous. Absent, il n'est simplement pas configuré.
///
/// ⚠️ Seule l'empreinte est gardée <b>par cette classe</b> ; la valeur brute reste dans
/// <c>IConfiguration</c> et dans l'environnement du conteneur tant que le script ne l'a pas
/// retirée de <c>.env</c>, ce qu'il fait dès qu'un compte existe.
/// </summary>
public sealed class CodeInstallation
{
    public const string Alphabet = "ABCDEFGHJKMNPQRSTUVWXYZ23456789";
    public const int Longueur = 20;

    /// <summary>Au-delà, une saisie n'est même pas hachée : aucun code n'est si long.</summary>
    private const int LongueurMaximaleSaisie = 100;

    private readonly byte[]? _empreinte;

    private CodeInstallation(byte[]? empreinte) => _empreinte = empreinte;

    public bool Configure => _empreinte is not null;

    /// <summary>Retire espaces et tirets — y compris ceux qu'un copier-coller apporte — et met en majuscules.</summary>
    public static string Normaliser(string saisie) =>
        new(saisie.Where(c => !char.IsWhiteSpace(c) && c is not ('-' or '‐' or '‑' or '‒' or '–' or '—'))
            .Select(char.ToUpperInvariant).ToArray());

    /// <summary>Un code neuf. Pour la série de tests : le script tire le sien.</summary>
    public static string Tirer() =>
        new(Enumerable.Range(0, Longueur).Select(_ => Alphabet[RandomNumberGenerator.GetInt32(Alphabet.Length)]).ToArray());

    public static CodeInstallation Lire(IConfiguration configuration)
    {
        var brut = configuration["Installation:Code"];

        if (string.IsNullOrWhiteSpace(brut)) return new CodeInstallation(null);

        var code = Normaliser(brut);

        if (code.Length != Longueur || code.Any(c => !Alphabet.Contains(c)))
        {
            throw new InvalidOperationException(
                $"Installation:Code doit compter {Longueur} symboles parmi {Alphabet} : configuré à moitié. "
                + "Le script en tire un (KLEAN_CODE_INSTALLATION dans .env). À la main : "
                + "tr -dc 'ABCDEFGHJKMNPQRSTUVWXYZ23456789' < /dev/urandom | head -c 20 ; "
                + "sans assistant, retirer la variable.");
        }

        return new CodeInstallation(Empreinte(code));
    }

    public bool Correspond(string? saisie)
    {
        if (_empreinte is null || string.IsNullOrEmpty(saisie) || saisie.Length > LongueurMaximaleSaisie)
        {
            return false;
        }

        return CryptographicOperations.FixedTimeEquals(Empreinte(Normaliser(saisie)), _empreinte);
    }

    private static byte[] Empreinte(string code) => SHA256.HashData(Encoding.UTF8.GetBytes(code));
}
```

```csharp
        _entrepriseInstallation = Guid.NewGuid();
```

```csharp
public sealed record NouvelleInstallation(

/// <summary>
/// Crée l'entreprise et son premier administrateur, en une transaction (SPEC.md, étape 34,
/// lot A2). Commune à l'amorçage par variables — au propriétaire — et à l'assistant —
/// sous la RLS. Jamais recopiée : deux créations finiraient par diverger.
///
/// L'identifiant de l'entreprise : sous la RLS, celui que la requête a posé
/// (<see cref="ITenantContext.PoserEntrepriseInstallation"/>) — la politique d'Entreprises n'en
/// accepte pas d'autre ; au propriétaire, un neuf.
/// </summary>
public sealed class ServiceInstallation(KleanDbContext db, UserManager<Utilisateur> utilisateurs, ITenantContext tenant)
{
    /// <summary>Espace du verrou consultatif. 21 et 22 sont pris (catalogue, stock).</summary>
    internal const int EspaceVerrou = 34;

    public async Task<ResultatInstallation> CreerAsync(NouvelleInstallation demande, CancellationToken annulation)
    {
        Guid entrepriseId;
        if (tenant.FiltrageActif)
        {
            entrepriseId = tenant.EntrepriseId
                ?? throw new InvalidOperationException("Sous la RLS, l'entreprise d'installation doit être posée avant la création.");
        }
        else
        {
            entrepriseId = Guid.NewGuid();
        }

        // Filet : le réglage de la RLS se pose à l'ouverture de la connexion (BasculeRoleApplicatif).
        // Une connexion déjà ouverte — une transaction de l'appelant — porterait celui d'avant.
        if (db.Database.GetDbConnection().State != System.Data.ConnectionState.Closed)
        {
            throw new InvalidOperationException("Connexion déjà ouverte : le réglage de la RLS serait celui d'avant.");
        }

        await using var transaction = await db.Database.BeginTransactionAsync(annulation);

        // Deux installations simultanées : la seconde attend ici, puis relit les comptes. Aucune
        // contrainte ne remplace ce verrou — rien n'interdit deux entreprises.
        await db.Database.ExecuteSqlAsync($"SELECT pg_advisory_xact_lock({EspaceVerrou}, 0)", annulation);

        // AspNetUsers est hors de la RLS (CLAUDE.md §7) : cette lecture voit tous les comptes.
        if (await db.Users.AnyAsync(annulation))
        {
            return new ResultatInstallation(IssueInstallation.DejaInstallee);
        }

        db.Entreprises.Add(new Entreprise
        {
            Id = entrepriseId,
            RaisonSociale = demande.RaisonSociale,
            Siret = demande.Siret,
            Territoire = demande.Territoire,
            DateCreation = DateTime.UtcNow
        });

        try
        {
            await db.SaveChangesAsync(annulation);
        }
        catch (DbUpdateException erreur) when (erreur.InnerException is PostgresException
                                                { SqlState: PostgresErrorCodes.UniqueViolation } violation
                                            && violation.ConstraintName == "IX_Entreprises_Siret")
        {
            // Invisible sous la RLS, l'orpheline se trahit par l'unicité de son SIRET. La transaction
            // est avortée ; sortir sans valider la défait.
            return new ResultatInstallation(IssueInstallation.SiretPris, EtatInstallation.MessageOrpheline);
        }

        var administrateur = new Utilisateur
        {
            // Identity refuse un UserName vide : la même valeur que Email (CLAUDE.md §6).
            UserName = demande.Email,
            Email = demande.Email,
            EmailConfirmed = true,
            EntrepriseId = entrepriseId,
            Nom = demande.Nom,
            Prenom = demande.Prenom,
            DateCreation = DateTime.UtcNow,
            Actif = true,
            MotDePasseProvisoire = demande.MotDePasseProvisoire
        };

        // Sur un refus, la transaction se défait en sortant : aucune entreprise sans compte.
        var creation = await utilisateurs.CreateAsync(administrateur, demande.MotDePasse);
        if (!creation.Succeeded) return new ResultatInstallation(IssueInstallation.Refusee, Messages(creation));

        var role = await utilisateurs.AddToRoleAsync(administrateur, RolesKlean.Administrateur);
        if (!role.Succeeded) return new ResultatInstallation(IssueInstallation.Refusee, Messages(role));

        await transaction.CommitAsync(annulation);
        return new ResultatInstallation(IssueInstallation.Creee);
    }

    public static string Messages(IdentityResult resultat) =>
        string.Join(" ; ", resultat.Errors.Select(e => e.Description));
}
```

```csharp
    /// La clé d'une adresse : IPv4 telle quelle (une IPv4 encapsulée en IPv6 ramenée à IPv4),
    /// IPv6 regroupée par son /64 — un seul hôte en possède des milliards, et tournerait dedans.
    /// </summary>
    public static string CleDAdresse(System.Net.IPAddress? adresse)
    {
        if (adresse is null) return AdresseInconnue;
        if (adresse.IsIPv4MappedToIPv6) adresse = adresse.MapToIPv4();
        if (adresse.AddressFamily != System.Net.Sockets.AddressFamily.InterNetworkV6) return adresse.ToString();

        Array.Clear(octets, 8, 8);
        return new System.Net.IPAddress(octets) + "/64";
```

```csharp
/// L'assistant d'installation (SPEC.md, étape 34, lot A2) : deux routes anonymes, gardées par le
/// code d'installation.
///
/// ⚠️ <b>Sous la RLS, jamais au-dessus.</b> Aucun <c>DesactiverFiltrage</c> — il lèverait,
/// dans une requête HTTP. L'entreprise tirée par <c>PoserEntrepriseInstallation</c> devient
/// celle de la requête.
///
/// ⚠️ <b>Le POST n'ouvre aucune session</b> : la connexion qui suit fait équiper le second
/// facteur, par le parcours de l'étape 23.
/// </summary>
[ApiController]
[Route("api/installation")]
[AllowAnonymous]
public partial class InstallationController(
    KleanDbContext db,
    ITenantContext tenant,
    ServiceInstallation installation,
    CodeInstallation code,
    EtatInstallation etat,
    LimiteurDebit debit) : ControllerBase
{
    /// <summary>Début du refus d'un code faux : l'écran s'en sert pour revenir au premier écran.</summary>
    public const string DebutRefusCode = "Code d'installation incorrect";

    private const string DejaInstallee = "KLEAN est déjà installé : connectez-vous.";

    [HttpGet]
    public async Task<ActionResult<EtatInstallationDto>> Lire(CancellationToken annulation)
    {
        if (!debit.Autoriser($"installation-lecture:adresse:{Adresse}",
                PlafondsDebit.LecturesInstallationParAdresse, PlafondsDebit.FenetreLecturesInstallation))
        {
            return TropDeTentatives();
        }

        return new EtatInstallationDto(await InstalleeAsync(annulation));
    }

    [HttpPost]
    public async Task<IActionResult> Installer(InstallationDto dto, CancellationToken annulation)
    {
        var codeJuste = code.Correspond(dto.Code);

        if (!debit.Autoriser(
                $"installation{(codeJuste ? "-bon-code" : "")}:adresse:{Adresse}",
                codeJuste ? PlafondsDebit.InstallationsBonCodeParAdresse : PlafondsDebit.InstallationsParAdresse,
                PlafondsDebit.FenetreInstallations))
        {
            return TropDeTentatives();
        }

        if (User.Identity?.IsAuthenticated == true || await InstalleeAsync(annulation)) return Conflict(DejaInstallee);

        if (!codeJuste)
        {
            return debit.Autoriser("installation:codes-faux:global", PlafondsDebit.CodesFauxGlobaux, PlafondsDebit.FenetreInstallations)
                ? BadRequest($"{DebutRefusCode}. Il s'affiche à la fin de l'installation sur le serveur, et par : sudo klean code")
                : TropDeTentatives();
        }

        var saisie = Saisie.De(dto);
        if (saisie.Refus() is { } message) return BadRequest(message);

        if (etat.EntrepriseOrpheline) return Conflict(EtatInstallation.MessageOrpheline);

        tenant.PoserEntrepriseInstallation();

        var resultat = await installation.CreerAsync(new NouvelleInstallation(
            saisie.RaisonSociale, saisie.Siret, Enum.Parse<Territoire>(saisie.Territoire),
            saisie.Email, saisie.Nom, saisie.Prenom, saisie.MotDePasse,
            // Choisi par le patron lui-même : pas provisoire.
            MotDePasseProvisoire: false), annulation);

        if (resultat.Issue == IssueInstallation.Creee) etat.Installee = true;

        return resultat.Issue switch
        {
            IssueInstallation.Creee => StatusCode(StatusCodes.Status201Created),
            IssueInstallation.DejaInstallee => Conflict(DejaInstallee),
            IssueInstallation.SiretPris => Conflict(resultat.Message),
            _ => BadRequest(resultat.Message)
        };
    }

    private string Adresse => LimiteurDebit.CleDAdresse(HttpContext.Connection.RemoteIpAddress);

    /// <summary>« Installée » ne revient jamais en arrière : une fois vue, la base n'est plus interrogée.</summary>
    private async Task<bool> InstalleeAsync(CancellationToken annulation)
    {
        if (!etat.Installee && await db.Users.AnyAsync(annulation)) etat.Installee = true;
        return etat.Installee;
    }

    private ObjectResult TropDeTentatives() =>
        StatusCode(StatusCodes.Status429TooManyRequests, "Trop de tentatives. Réessayer dans quelques minutes.");

    /// <summary>La saisie, normalisée une seule fois ; <c>null</c> vaut vide.</summary>
    private sealed record Saisie(string RaisonSociale, string Siret, string Territoire, string Email,
        string Nom, string Prenom, string MotDePasse)
    {
        public static Saisie De(InstallationDto dto) => new(
            (dto.RaisonSociale ?? "").Trim(),
            new string((dto.Siret ?? "").Where(c => !char.IsWhiteSpace(c)).ToArray()),
            dto.Territoire ?? "",
            (dto.Email ?? "").Trim(),
            (dto.Nom ?? "").Trim(),
            (dto.Prenom ?? "").Trim(),
            dto.MotDePasse ?? "");

        public string? Refus()
        {
            if (RaisonSociale.Length is 0 or > 200) return "La raison sociale est obligatoire, 200 caractères au plus.";
            if (!SiretValide().IsMatch(Siret)) return "Le SIRET compte 14 chiffres.";
            if (!Enum.GetNames<Models.Territoire>().Contains(Territoire))
                return $"Territoire inconnu. Valeurs acceptées : {string.Join(", ", Enum.GetNames<Models.Territoire>())}.";
            if (Email.Length > 256 || !MailAddress.TryCreate(Email, out var adresse) || adresse.Address != Email)
                return "L'adresse électronique de l'administrateur n'est pas valide.";
            if (Nom.Length is 0 or > 100) return "Le nom est obligatoire, 100 caractères au plus.";
            if (Prenom.Length is 0 or > 100) return "Le prénom est obligatoire, 100 caractères au plus.";
            // Le mot de passe n'est pas vérifié ici : Identity est l'autorité, et parle français (CLAUDE.md §6).
            return null;
        }
    }

    [GeneratedRegex("^[0-9]{14}$")]
    private static partial Regex SiretValide();
}
```
