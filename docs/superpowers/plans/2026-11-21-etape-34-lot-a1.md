# Étape 34, lot A1 — Installer et tenir à jour : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** qu'un patron installe KLEAN sur un serveur neuf Debian ou Ubuntu par une seule commande, puis le tienne à jour, le sauvegarde et le restaure par la commande `klean`, sans ouvrir un fichier.

**Architecture:** une version publiée est faite de deux images sur `ghcr.io`, d'une archive (`docker-compose.yml` sans `build:`, le script `klean`, ses fonctions, le fichier cron, `VERSION`, `env.modele`) et d'un `installer.sh`, chacun avec son empreinte SHA-256. `installer.sh` installe Docker, télécharge et vérifie l'archive, la pose dans `/opt/klean`, puis passe la main à `klean installer`. Toute la logique vit dans `klean` ; ce qui se calcule sans Docker ni réseau vit dans `fonctions.sh`, éprouvé par une série bash dans un conteneur Debian.

**Tech Stack:** bash 5 (Debian 12 / Ubuntu 22.04+), coreutils, docker compose v2, GitHub Actions, `ghcr.io`, `shellcheck`. Aucune dépendance ajoutée au projet.

**Référence :** `SPEC.md`, « # Étape 34 — Installer KLEAN sans être informaticien », section « Lot A1 ». `CLAUDE.md` §2, §6 (trousseau), §10 (pièges de l'exploitation, `pg_dump` et les rôles), §14 (périmètre, migrations, git). `DEPLOIEMENT.md` §4 et §5.

---

## Décisions propres à ce plan

1. **Transition jusqu'au lot A2.** Sans assistant, l'API exige l'amorçage par variables (`AmorcageService`), sinon elle ne démarre pas. A1 garde donc ce chemin : le script demande la raison sociale et l'adresse de l'administrateur, **tire** un mot de passe provisoire, l'affiche **une seule fois** à la fin, puis le **retire de `.env`** dès qu'un compte existe. Le mot de passe est provisoire (étape 24) : la première connexion le fait remplacer, puis équiper le second facteur. Le script génère déjà `KLEAN_CODE_INSTALLATION` et `KLEAN_GEOCODAGE`, que l'API ignore jusqu'à A2 et A3. A2 remplacera la transition.
2. **La restauration repart d'une base vide** : `DROP DATABASE … WITH (FORCE)`, `CREATE DATABASE`, puis `pg_restore` sans `--clean`. `--clean` ne supprime que les objets présents dans la sauvegarde : après une mise à jour, les tables ajoutées par la nouvelle version resteraient, et la mise à jour suivante échouerait en les recréant. `DEPLOIEMENT.md` §4 est mis à jour en conséquence.
3. **`klean revenir` ne joue aucune migration descendante.** Il remet les fichiers de la version précédente et restaure la sauvegarde prise juste avant la mise à jour.
4. **Ordre de la mise à jour** : téléchargement pendant que l'ancienne version tourne, puis sauvegarde (l'API doit tourner, le trousseau se lit dans son conteneur), puis arrêt de l'API, migration, démarrage. Les saisies faites entre la sauvegarde et l'arrêt — quelques secondes — seraient perdues par un `revenir` : c'est dit dans le message de `revenir`.
5. **Le dépôt GitHub et la première étiquette sont des gestes de l'utilisateur** (tâche 0 et tâche 12) : créer le dépôt public, pousser, rendre les deux paquets `ghcr.io` publics. Aucun agent ne les fait.

```bash
# shellcheck shell=bash
# Fonctions de l'installation de KLEAN (SPEC.md, étape 34, lot A1), sans effet de bord
# hors de leurs arguments : aucune n'appelle Docker ni le réseau. Sourcées par
# `klean` et par tests/tests.sh, c'est ce qui les rend éprouvables.

# Le dépôt qui publie les versions, `propriétaire/nom`. deploiement/publier.sh
# remplace @DEPOT@ ; une variable d'environnement l'emporte, pour les essais.
KLEAN_DEPOT_GITHUB="${KLEAN_DEPOT_GITHUB:-@DEPOT@}"

# Base32 sans caractères ambigus — ni 0, O, 1, I ni L — : 31 symboles. Jamais `$`, que
# docker compose interprète dans .env.
ALPHABET_CODE='ABCDEFGHJKMNPQRSTUVWXYZ23456789'

# Un octet aléatoire, de 0 à 255.
octet_aleatoire() {
  od -An -N1 -tu1 /dev/urandom | tr -d ' \n'
}

# Le code d'installation de l'assistant (lot A2) : 20 symboles, environ 99 bits.
generer_code() {
  local code='' octet
  while [ "${#code}" -lt 20 ]; do
    octet=$(octet_aleatoire)
    # 248 = 8 × 31. Au-delà, l'octet est rejeté : sinon les premiers symboles de
    # l'alphabet sortiraient plus souvent que les autres.
    if [ "$octet" -lt 248 ]; then
      code+="${ALPHABET_CODE:$((octet % 31)):1}"
    fi
  done
  printf '%s\n' "$code"
}

# Un secret hexadécimal de $1 octets. Hexadécimal : un « ; » ou un « = » couperait la
# chaîne de connexion de PostgreSQL (.env.example).
generer_secret() {
  od -An -N"$1" -tx1 /dev/urandom | tr -d ' \n'
  printf '\n'
}

# Un mot de passe provisoire qui passe les règles d'Identity (CLAUDE.md §6) : 16
# caractères, une majuscule, une minuscule et un chiffre au moins.
generer_mot_de_passe() {
  local alphabet='ABCDEFGHJKMNPQRSTUVWXYZabcdefghjkmnpqrstuvwxyz23456789'
  local mot octet
  while :; do
    mot=''
    while [ "${#mot}" -lt 16 ]; do
      octet=$(octet_aleatoire)
      # 216 = 4 × 54, pour la même raison que dans generer_code.
      if [ "$octet" -lt 216 ]; then
        mot+="${alphabet:$((octet % 54)):1}"
      fi
    done
    if [[ "$mot" =~ [A-Z] && "$mot" =~ [a-z] && "$mot" =~ [0-9] ]]; then
      printf '%s\n' "$mot"
      return
    fi
  done
}
```

```bash
# La valeur de la clé $2 dans le fichier .env $1, ou une chaîne vide. Les apostrophes
# qui l'entourent, posées par poser_env, sont retirées.
lire_env() {
  local valeur
  valeur=$(grep -E "^$2=" "$1" 2> /dev/null | tail -n 1 | cut -d= -f2-) || true
  valeur="${valeur#\'}"
  valeur="${valeur%\'}"
  printf '%s\n' "$valeur"
}

# Pose $2=$3 dans le fichier .env $1 : remplace la ligne de la clé, ou l'ajoute.
#
# Une valeur hors de [A-Za-z0-9._@:/+-] est écrite entre apostrophes : docker compose
# lit alors la valeur littéralement, sans interpréter `$`. Une apostrophe dans la
# valeur n'a pas d'écriture sûre : refusée.
#
# Le fichier est réécrit à côté puis renommé : jamais de .env à moitié écrit.
poser_env() {
  local fichier="$1" cle="$2" valeur="$3" ligne temporaire
  case "$valeur" in
    *"'"*)
      printf 'Valeur refusée pour %s : une apostrophe ne peut pas figurer dans .env.\n' "$cle" >&2
      return 1
      ;;
  esac
  if [[ "$valeur" =~ ^[A-Za-z0-9._@:/+-]*$ ]]; then
    ligne="$cle=$valeur"
  else
    ligne="$cle='$valeur'"
  fi
  temporaire=$(mktemp "$fichier.XXXXXX")
  if grep -qE "^$cle=" "$fichier" 2> /dev/null; then
    # ENVIRON plutôt que `awk -v` : -v interprète les barres obliques inverses.
    LIGNE="$ligne" CLE="$cle" awk 'index($0, ENVIRON["CLE"] "=") == 1 { print ENVIRON["LIGNE"]; next } { print }' \
      "$fichier" > "$temporaire"
  else
    { cat "$fichier" 2> /dev/null || true; printf '%s\n' "$ligne"; } > "$temporaire"
  fi
  chmod 600 "$temporaire"
  mv -f "$temporaire" "$fichier"
}

# Ajoute $2=$3 seulement si la clé $2 est absente. C'est ce qui rend une seconde
# installation et une mise à jour sûres : un mot de passe PostgreSQL régénéré face à
# un volume existant rendrait l'instance inaccessible (CLAUDE.md §10).
completer_env() {
  if ! grep -qE "^$2=" "$1" 2> /dev/null; then
    poser_env "$1" "$2" "$3"
  fi
}
```

```bash
# La version d'une URL de version GitHub : …/releases/tag/v1.2.3 donne 1.2.3. Échoue
# sur toute autre forme : la redirection de `releases/latest` sans version publiée
# mène à …/releases.
version_depuis_url() {
  local fin="${1##*/}"
  fin="${fin#v}"
  if [[ "$fin" =~ ^[0-9]+\.[0-9]+\.[0-9]+$ ]]; then
    printf '%s\n' "$fin"
  else
    return 1
  fi
}

url_archive() {
  printf 'https://github.com/%s/releases/download/v%s/klean-%s.tar.gz\n' "$KLEAN_DEPOT_GITHUB" "$1" "$1"
}

# Lue par sa redirection, sans l'API de GitHub : ni clé, ni plafond de débit.
url_derniere_version() {
  printf 'https://github.com/%s/releases/latest\n' "$KLEAN_DEPOT_GITHUB"
}

# Le préfixe des images. ghcr.io exige un propriétaire en minuscules.
nom_images() {
  printf 'ghcr.io/%s/klean\n' "$(printf '%s' "${KLEAN_DEPOT_GITHUB%%/*}" | tr '[:upper:]' '[:lower:]')"
}

# $1 : l'ID de /etc/os-release ; $2 : l'architecture selon dpkg. Les images ne sont
# publiées qu'en amd64 en V1 (SPEC.md, étape 34).
systeme_pris_en_charge() {
  case "$1" in debian | ubuntu) ;; *) return 1 ;; esac
  [ "$2" = amd64 ]
}

# $1 : MemTotal de /proc/meminfo, en kio. 1 Go, moins la part que le noyau se réserve.
memoire_suffisante() {
  [ "$1" -ge 900000 ]
}

# $1 : les adresses du domaine, une par ligne ; $2 : celles de la machine. Écrit les
# adresses du domaine absentes de la machine. Réussit si toutes y sont ; échoue si une
# manque, ou si le domaine n'a aucune adresse.
#
# A et AAAA ensemble : Let's Encrypt préfère IPv6, et une AAAA oubliée vers une autre
# machine fait échouer le certificat sans rien dire.
adresses_etrangeres() {
  local domaine="$1" machine="$2" adresse etrangeres=0
  [ -n "$domaine" ] || return 1
  while IFS= read -r adresse; do
    [ -n "$adresse" ] || continue
    if ! printf '%s\n' "$machine" | grep -qxF "$adresse"; then
      printf '%s\n' "$adresse"
      etrangeres=1
    fi
  done <<< "$domaine"
  return "$etrangeres"
}

# Les sauvegardes à supprimer. $1 : les fichiers, un par ligne, nommés
# <préfixe>-AAAA-MM-JJTHHMM[…] ; $2 : la date limite AAAA-MM-JJ, strictement avant
# laquelle une sauvegarde part. Ne rend jamais la plus récente : la rotation ne
# supprime pas la dernière copie, même hors délai.
sauvegardes_a_supprimer() {
  local fichiers dernier fichier nom date
  fichiers=$(printf '%s\n' "$1" | grep -v '^$' | sort)
  dernier=$(printf '%s\n' "$fichiers" | tail -n 1)
  while IFS= read -r fichier; do
    [ -n "$fichier" ] && [ "$fichier" != "$dernier" ] || continue
    nom="${fichier##*/}"
    date="${nom#*-}"
    date="${date:0:10}"
    if [[ "$date" < "$2" ]]; then
      printf '%s\n' "$fichier"
    fi
  done <<< "$fichiers"
}
```

```bash
#!/usr/bin/env bash
# Fabrique les fichiers d'une version publiée (SPEC.md, étape 34, lot A1) :
#   klean-<version>.tar.gz          docker-compose.yml sans build:, klean, fonctions.sh,
#                                   klean.cron, env.modele, VERSION
#   installer.sh                    @DEPOT@ et @VERSION@ remplacés
#   *.sha256                        une empreinte par fichier publié
#
#     deploiement/publier.sh 1.2.3 proprietaire/depot dist
set -Eeuo pipefail

version="${1:-}"
depot="${2:-}"
sortie="${3:-}"

[[ "$version" =~ ^[0-9]+\.[0-9]+\.[0-9]+$ ]] || { printf 'Version invalide : « %s » (attendu : 1.2.3).\n' "$version" >&2; exit 1; }
[[ "$depot" =~ ^[A-Za-z0-9_.-]+/[A-Za-z0-9_.-]+$ ]] || { printf 'Dépôt invalide : « %s » (attendu : proprietaire/nom).\n' "$depot" >&2; exit 1; }
[ -n "$sortie" ] || { printf 'Dossier de sortie manquant.\n' >&2; exit 1; }

racine=$(cd "$(dirname "$0")/.." && pwd)
travail=$(mktemp -d)
trap 'rm -rf "$travail"' EXIT
mkdir -p "$sortie"

# Le serveur n'a pas le code source : un `build:` resté dans le compose ferait échouer
# `docker compose up` quand une image manque, au lieu de la télécharger.
sed '/^    build: /d' "$racine/docker-compose.yml" > "$travail/docker-compose.yml"
sed "s|@DEPOT@|$depot|g" "$racine/deploiement/fonctions.sh" > "$travail/fonctions.sh"
cp "$racine/deploiement/klean" "$racine/deploiement/klean.cron" "$racine/deploiement/env.modele" "$travail/"
chmod 755 "$travail/klean"
printf '%s\n' "$version" > "$travail/VERSION"

tar czf "$sortie/klean-$version.tar.gz" -C "$travail" \
  docker-compose.yml klean fonctions.sh klean.cron env.modele VERSION
sed -e "s|@DEPOT@|$depot|g" -e "s|@VERSION@|$version|g" \
  "$racine/deploiement/installer.sh" > "$sortie/installer.sh"

cd "$sortie"
sha256sum "klean-$version.tar.gz" > "klean-$version.tar.gz.sha256"
sha256sum installer.sh > installer.sh.sha256
```

Run : `chmod +x deploiement/publier.sh deploiement/klean deploiement/installer.sh`

```bash
#!/usr/bin/env bash
# La commande d'exploitation de KLEAN (SPEC.md, étape 34, lot A1), installée dans
# /opt/klean et appelée par /usr/local/bin/klean.
#
#   sudo klean installer               première installation, ou reprise
#   sudo klean mettre-a-jour [1.2.3]   sans version : la dernière publiée

#   sudo klean sauvegarder             ce que fait la tâche de chaque nuit

DERNIERE_SAUVEGARDE=''

cmd_sauvegarder() {
  exiger_root
  local suffixe="${1:-}" horodatage nom temporaire
  horodatage=$(date +%Y-%m-%dT%H%M)
  install -d -m 700 "$SAUVEGARDES" "$TROUSSEAU"

  local horodatage="$1" temporaire empreinte precedente
  temporaire=$(mktemp "$TROUSSEAU/.partiel.XXXXXX")
  if ! compose exec -T api tar czf - -C /home/app/.aspnet DataProtection-Keys > "$temporaire"; then
    rm -f "$temporaire"

  fi

  # panne, et la sauvegarde de la base ne doit pas échouer pour autant.
  if ! tar tzf "$temporaire" | grep -q 'key-.*\.xml$'; then
    rm -f "$temporaire"
    avertir "Le trousseau ne contient encore aucune clé : rien à sauvegarder de ce côté."
    return

  precedente=$(cat "$TROUSSEAU/.empreinte" 2> /dev/null || true)
  if [ "$empreinte" = "$precedente" ]; then
    rm -f "$temporaire"
    return
  fi
  chmod 600 "$temporaire"
  mv -f "$temporaire" "$TROUSSEAU/trousseau-$horodatage.tgz"
  printf '%s\n' "$empreinte" > "$TROUSSEAU/.empreinte"
}
```

```bash
cmd_restaurer() {

# Repart d'une base vide, puis restaure : `pg_restore --clean` laisserait en place les
# tables qu'une version plus récente a ajoutées, et la mise à jour suivante échouerait
# en les recréant (plan de l'étape 34, décision 2).

# `revenir` ne le demande pas : il remet aussi les images d'avant.
restaurer_base() {

  compose up -d postgres
  attendre_postgres
  compose stop api
  compose exec -T postgres psql -U klean -d postgres -v ON_ERROR_STOP=1 \
    -c 'DROP DATABASE IF EXISTS klean WITH (FORCE)' \
    -c 'CREATE DATABASE klean OWNER klean'
  # Le rôle vit dans la grappe, pas dans la base : sur une machine neuve, il manque, et
  # pg_restore s'arrêterait sur les droits qui le nomment (CLAUDE.md §10).
  compose exec -T postgres psql -U klean -d klean -v ON_ERROR_STOP=1 -c \
    "DO \$\$ BEGIN IF NOT EXISTS (SELECT FROM pg_roles WHERE rolname = 'klean_app') THEN CREATE ROLE klean_app NOLOGIN NOSUPERUSER NOBYPASSRLS NOINHERIT; GRANT klean_app TO CURRENT_USER; END IF; END \$\$;"
  compose exec -T postgres pg_restore -U klean -d klean --no-owner --exit-on-error < "$sauvegarde" ||
    echouer "La restauration a échoué en cours de route : la base est incomplète. Relancez sudo klean restaurer avec une autre sauvegarde."
  restaurer_trousseau_si_vide
  if [ "$migrations" = migrer ]; then
    compose run --rm -T migrer || echouer "La base est restaurée, mais sa mise au niveau de la version installée a échoué : voir les lignes ci-dessus."
  fi
  compose up -d
}

# Le trousseau perdu avec la machine se restaure **avant** que l'API ne démarre :
# démarrée, elle pourrait créer une clé neuve, et le test ci-dessous passerait à tort.
# Un conteneur éphémère monte le même volume. Sans trousseau, chaque compte devrait
# rééquiper son second facteur (DEPLOIEMENT.md §10).
restaurer_trousseau_si_vide() {
  local archive
  if compose run --rm --no-deps -T --entrypoint sh api \
    -c 'ls /home/app/.aspnet/DataProtection-Keys 2> /dev/null | grep -q "^key-"'; then
    return
  fi
  archive=$(find "$TROUSSEAU" -maxdepth 1 -type f -name 'trousseau-*.tgz' | sort | tail -n 1)
  if [ -z "$archive" ]; then
    avertir "Trousseau absent, et aucune archive : chaque compte devra rééquiper son second facteur (DEPLOIEMENT.md §10)."
    return
  fi
  compose run --rm --no-deps -T --entrypoint tar api xzf - -C /home/app/.aspnet < "$archive"
}
```

```bash
os_release() { (. /etc/os-release && eval "printf '%s' \"\${$1:-}\""); }

installer_docker() {

  apt-get install -y -qq docker-ce docker-ce-cli containerd.io docker-compose-plugin
```

```bash
derniere_version() {
  local url
  url=$(curl -fsSLI -o /dev/null -w '%{url_effective}' "$(url_derniere_version)") ||

# Télécharge et vérifie l'archive de la version $1 dans versions/$1. Les versions
# déjà installées y restent : c'est ce que `revenir` remet en place.
telecharger_version() {
  local version="$1" dossier="$REPERTOIRE/versions/$1" archive url
  install -d -m 700 "$dossier"
  archive="$dossier/klean-$version.tar.gz"
  url=$(url_archive "$version")
  curl -fsSL -o "$archive" "$url" || echouer "Téléchargement impossible : $url"
  curl -fsSL -o "$archive.sha256" "$url.sha256" || echouer "Empreinte introuvable : $url.sha256"
  (cd "$dossier" && sha256sum -c --status "klean-$version.tar.gz.sha256") ||
    echouer "L'archive de la version $version ne correspond pas à son empreinte : rien n'est installé."
  tar xzf "$archive" -C "$dossier"

# Remplace les fichiers de /opt/klean par ceux de $1, chacun par `mv` (voir l'en-tête).
installer_fichiers() {
  local source="$1" fichier
  for fichier in $FICHIERS_VERSION; do
    install -m 600 "$source/$fichier" "$REPERTOIRE/.$fichier.nouveau"
    mv -f "$REPERTOIRE/.$fichier.nouveau" "$REPERTOIRE/$fichier"
  done
  chmod 700 "$REPERTOIRE/klean"
  install -m 644 "$REPERTOIRE/klean.cron" /etc/cron.d/klean
}

cmd_mettre_a_jour() {
  exiger_root
  local actuelle cible dossier
  actuelle=$(lire_env "$ENV" KLEAN_VERSION)
  cible="${1:-}"
  if [ -z "$cible" ]; then
    cible=$(derniere_version)
  fi
  [[ "$cible" =~ ^[0-9]+\.[0-9]+\.[0-9]+$ ]] || echouer "Version invalide : « $cible » (attendu : 1.2.3)."
  if [ "$cible" = "$actuelle" ]; then
    dire "KLEAN est déjà en version $actuelle."
    return
  fi

  telecharger_version "$cible"
  dossier="$REPERTOIRE/versions/$cible"
```
